# Inventory and Stock Management System

## Project Overview

The Inventory and Stock Management System is a web-based application developed using PHP and MySQL to manage products, categories, suppliers, purchases, sales, and stock transactions in an organized way.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Main Features

- User Login and Authentication
- Dashboard with inventory summary
- Product Management
- Category Management
- Supplier Management
- Purchase Management
- Sales Management
- Stock Management
- Stock Transaction Tracking
- Add, Update and Delete Records
- MySQL Database Integration

## Project Modules

1. **Dashboard** – Displays an overview of inventory data.
2. **Products** – Add, update, delete and manage products.
3. **Categories** – Organize products into categories.
4. **Suppliers** – Manage supplier details.
5. **Purchases** – Record product purchases.
6. **Sales** – Record product sales.
7. **Stock** – Manage available stock.
8. **Stock Transactions** – Track stock movements.

## Database

The project uses **MySQL** database for storing and managing inventory-related data. The database structure is provided in the `inventory_management.sql` file.

## Purpose

The main purpose of this project is to provide a simple and organized system for managing inventory records and monitoring stock-related activities.
